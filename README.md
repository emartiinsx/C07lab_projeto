Tema Escolhido:
Sistema de Gestão Comercial Imobiliária

Explicação do Tema:
O projeto consiste na modelagem de um banco de dados para um sistema imobiliário focado em agilizar o trabalho de corretores e facilitar o agendamento de clientes. O sistema mapeia os imóveis disponíveis e gerencia a carteira de cada corretor. Além disso, controla um histórico de agendamento de visitas (relacionamento N:M) que permite monitorar quais clientes visitaram quais propriedades. Por fim, o modelo gerencia a formalização de contratos de venda/aluguel, garantindo a integridade dos dados e a associação correta entre proprietários, clientes e corretores envolvidos na negociação.
